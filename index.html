HELP AT THE RELEVANT MOMENT

“What does this change mean?”

While the session is open, the companion observes the selected Git project and a small amount of changed source. Capture a command when you want its output included.

OBSERVE → REMEMBER → REASON

Code changes settle for 10 seconds. The local model connects new evidence to your work and suggests one useful next step.

Automatic reasoning: at most once per 90 seconds

Idle observation makes no model calls. Use /quiet to pause awareness or /quit to end the session.

AN ASSISTANT UNDER YOUR CONTROL

“What should I do next?”

Ask for a plan. The model can propose an action from checks you registered. You see its exact command and reason before approving it.

See the data boundaries ↗
01

Local inference

A downloaded Ollama model, accessed through loopback HTTP. No silent cloud fallback.

02

Scoped awareness

The selected Git repository and commands you explicitly capture. You can inspect context and stop observation.

03

Persistent local memory

A SQLite database on your machine. Inspect intentions, remove entries or forget a project's records.

04

Free preview

No subscription or usage collection. The application source is currently private; this is an early binary release.

ollama pull qwen3:1.7b
cd your-git-project
devcompanion init --goal "Finish the login flow"

Start ollama serve if your installation does not already run it. Initial setup needs internet. You can select another downloaded model with --model NAME.
